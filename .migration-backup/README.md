# SchoolFoundry - Comprehensive School Management System
A practical school management system built for the realities of African schools. Developed by [Jiggabyte Technology Limited](https://jiggabyte.com) in Lusaka, Zambia.

## The Problem
Many schools in Southern Africa still rely on paper records for receipts, payments, and student management. Internet connectivity is often unreliable, and complex software requires expensive IT departments that schools don't have.

## The SchoolFoundry Solution
SchoolFoundry offers a simple path away from paper:

1.  **SchoolFoundry Offline (Available Now):** A one-off hardware/software bundle (Thermal Printer + 10 Receipt Rolls) that works 100% offline. No monthly bills, no internet required.
2.  **SchoolFoundry Online (Coming Soon):** Access from any device, parent messages, and easier record sharing.
3.  **Future Plans:** Faster reporting, easier communication, and more helpful school insights.

## Tech Stack
- **Frontend:** React + Vite + Tailwind CSS v4 + Framer Motion
- **UI:** Shadcn/UI (Radix UI)
- **Deployment:** GitHub Pages
